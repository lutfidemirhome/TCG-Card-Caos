DOCUMENTATION


The Lamp Collection package contains over 40 different detailed lamps. Many lamp prefabs are available with different light colors (white, green, blue, pink and orange). 
You can change the color very easily by changing the emission color and the light color. All lamps with one exeption uses a white emission material, so you can change the emission color to the color you want.
The asset supports all three render pipelines (Builtin RP, URP and HDRP). 

If you want to add more details to the lamps you could add my "Screw Heads Pack - Free".
https://assetstore.unity.com/packages/slug/170388

Please note:

When importing the asset to your project you only need to import the desired render pipeline folder (Builtin RP, URP, HDRP) and the General folder.
If you switch between Builtin RP demo, URP demo and HDRP demo don‘t forget to remove or add the RenderPipelineAsset in Project Settings -> Graphics -> Scriptable Render Pipeline Settings. 
If you want to use the URP or HDRP demo don't forget to install URP or HDRP from the package manager.

You can find the RenderPipelineAsset in URP/RenderPipeline/UniversalRenderPipelineAsset
and
You can find the RenderPipelineAsset in HDRP/HDRPDefaultResources/HDRPDefaultResources


Texture resolution: 1024 x 1024, 2048 x 2048 and 4096 x 4096

- 297 prefabs ready to use with Builtin RP, URP and HDRP.
