Main Menu UI
==============

The menu layout lives in two places:

1. Scene (edit here for layout + wiring)
   Assets/Scenes/MenuScene.unity
   Hierarchy root: MainMenuCanvas

2. Prefab (created when you run Build Main Menu UI)
   Assets/UI/MainMenu/MainMenuCanvas.prefab

3. Photoshop slices go here:
   Assets/UI/MainMenu/Art/

4. Translations:
   Assets/Resources/Localization/LocalizationTable.asset

Unity menu:
  TCG Card Caos → UI → Open Main Menu Scene
  TCG Card Caos → UI → Build Main Menu UI
