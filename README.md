# TCG Card Chaos

First-person card shop organization game (Unity 2022.3.41f1).

## First open (Unity 6)

1. Open this project with **Unity 6 LTS** and confirm upgrade if asked.
2. Top menu: **TCG Card Chaos → Setup First Person Playground**
3. Press **Play** to test.

### Controls

| Input | Action |
|---|---|
| **W A S D** | Move |
| **Mouse** | Look around |
| **Left Shift** | Sprint |
| **Escape** | Unlock / lock cursor |

## Project layout

- `Assets/Scenes/` — game scenes
- `Assets/Scripts/` — C# scripts
- `Assets/Data/` — card database (CSV/JSON, ScriptableObjects)
- `Assets/Prefabs/` — cards, shelves, interactables
- `Assets/Art/` — models, textures, card art
